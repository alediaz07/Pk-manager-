# Manual de Cocina (Pantalla KDS) — Pollos Karen Manager

## 1. Acceso Dedicado
- Inicie sesión en la tablet o pantalla de cocina con una cuenta de rol **Cocina (`cocina`)**.
- El sistema abrirá exclusivamente la **Pantalla de Cocina (KDS)** a pantalla completa, sin menús de caja, precios ni módulos administrativos.

## 2. Lectura de Comandas
La pantalla se divide en tres columnas claras:
1. **Autorizadas (Nuevas)**: comandas recién aprobadas por salón/caja listas para iniciar.
2. **En Preparación**: comandas actualmente en proceso en cocina.
3. **Listas para Despacho**: últimas comandas terminadas para retiro por salón o mensajero.

Cada tarjeta muestra únicamente:
- Número de orden y tipo de servicio (**Mesa**, **Ventana** o **Exprés**).
- Cantidad, nombre del platillo, **proteína seleccionada** en casados y **observaciones/modificaciones** en destaque.
- Tiempo transcurrido con semáforo visual:
  - Normal (< 10 min)
  - Alerta amarilla (10 a 19 min)
  - Alerta roja (≥ 20 min)

## 3. Acciones Permitidas
- Toque **Iniciar Preparación** cuando empiece a cocinar una comanda.
- Toque **Marcar Lista** cuando el pedido esté terminado y emplatado/empacado.
- Utilice los botones superiores para activar/silenciar el aviso sonoro de nuevas órdenes, mantener la pantalla encendida (**Wake Lock**) o alternar pantalla completa.
