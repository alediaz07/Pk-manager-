# Guía de comandas físicas — Pollos Karen Manager

Cocina no utiliza cuentas, tablets ni pantallas digitales. Recibe la comanda física emitida por el colaborador desde POS.

- Prepare las cantidades, proteínas y observaciones impresas.
- Comunique al colaborador que el pedido está listo; salón/caja registra la entrega en POS.
- Las reimpresiones deben verificarse con el número de pedido para no preparar dos veces la misma orden.
- Si la impresora falla, utilice una comanda manual con el número de pedido y las observaciones, coordinada desde POS.
